# Product Overview

**Chorus** は、AIペルソナを活用したA/Bテストプラットフォームです。デザイナーやプロダクトチームが、実際のユーザーリサーチなしに複数のペルソナ視点でデザイン評価を実施できます。

## Core Capabilities

- **ペルソナ管理**: プリセットまたはAI生成のペルソナを作成・編集し、ユーザー属性（年齢・職業・価値観など）を定義する
- **デザインA/Bテスト実行**: Figma URL・サイトURL・画像アップロードの3入力方式でデザインをキャプチャし、Amazon Bedrock上のLLMがペルソナ視点で比較評価する
- **ペルソナインタビュー**: 任意のペルソナにチャット形式で質問し、ペルソナとして回答を得る
- **評価レポート**: 勝者・スコア（usability / aesthetics / clarity / engagement / trust）・理由をまとめたレポートをCSVエクスポートできる

## Target Use Cases

- プロトタイプ段階のデザイン比較（ユーザーテストの前段として）
- 多様なユーザーセグメントへの訴求力チェック
- ペルソナへのクイックインタビューによる仮説検証

## Value Proposition

実際のユーザーリクルーティングなしに、多様なペルソナによるA/Bテストと定量スコアリングを即座に実行できる点が差別化要因です。
